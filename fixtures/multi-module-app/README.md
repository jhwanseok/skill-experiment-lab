# multi-module-app (스텁)

모듈/의존관계가 얽힌, 상대적으로 규모가 있는 앱. 구조/탐색 이해 archetype(예: graphify류 지식 그래프 도구)을 테스트할 때 쓴다.

graphify의 첫 실험은 이 픽스처 대신 `jhwanseok.github.io` 저장소 자체를 읽기 전용으로 분석하는 방식을 쓰기로 했다(자세한 내용은 `jhwanseok.github.io`의 `plug-in-elegant-robin.md` 계획 참고) — 지식 그래프의 가치는 파일 수가 많을수록 커지는데, 초소형 픽스처로는 효과가 드러나지 않기 때문이다.

이 픽스처는 향후 다른 구조/탐색 계열 스킬을 테스트할 때, 또는 코드 변경까지 필요한 구조 관련 실험이 생길 때 채운다.
